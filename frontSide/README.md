# Waleed React Portfolio

Modern dark/gradient portfolio built with Create React App and React Icons.

## Run

```bash
npm install
npm start
```

## Images

Put your own files in:

`public/images/`

Required:
- profile.png
- coding.jpg
- furniro.jpg
- karlihealth.jpg
- business.jpg
- dashboard.jpg

Put your CV at:

`public/cv.pdf`

Then replace the sample email, phone, social links and project links in the components.
